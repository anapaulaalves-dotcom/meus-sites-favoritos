
# Meus Sites Favoritos

## Sobre o projeto

Este projeto foi desenvolvido como atividade prática de desenvolvimento web, utilizando HTML e CSS.

O objetivo é criar uma página para organizar e apresentar cinco sites favoritos, facilitando o acesso a plataformas utilizadas para estudos, pesquisas e entretenimento.

## Tecnologias utilizadas

- HTML5
- CSS3

## Sites selecionados

1. Google Acadêmico - Pesquisas acadêmicas.
2. SciELO - Artigos científicos.
3. Khan Academy - Plataforma educacional.
4. Canva - Criação de materiais visuais.
5. YouTube - Vídeos e conteúdos educativos.

## Como executar

1. Baixe o projeto.
2. Abra a pasta.
3. Clique duas vezes no arquivo index.html.
4. A página será aberta no navegador.
